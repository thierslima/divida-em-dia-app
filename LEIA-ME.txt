COMO GERAR O APK NO WINDOWS
1. Instale o Android Studio pelo site oficial:
   https://developer.android.com/studio
2. Abra o Android Studio pelo menos uma vez e deixe instalar o Android SDK.
3. No SDK Manager, confirme que "Android SDK Platform 35" está instalado.
4. Feche o Android Studio.
5. Dê dois cliques em GERAR_APK.bat.
6. Na primeira execução o script baixa o Gradle 8.9.
7. Ao terminar, aparecerá o arquivo:
   DividaEmDia-v1.0.apk

OBSERVAÇÃO
O APK não foi compilado dentro do ambiente do ChatGPT porque este ambiente não possui o Android SDK/Build Tools instalados. O projeto Android e o código dos lembretes nativos estão completos e preparados para compilação.
